# Password reset trusts emails nobody confirmed

Signing up never proves you own the email, yet a Password reset hands the User to whoever can read that email. So if someone signs up with an email that isn't theirs, by typo or on purpose, the email's real owner can reset the password and see that User's finances. We accept this rather than adding email confirmation at Sign up, which would stop signing up from signing you straight in and make the feature bigger. The person who entered the wrong email carries the risk. Confirmation can be added later without changing how a Password reset works.
