# The Guest is one shared User

Visitors who want to try the app without registering all sign in as the same Guest User, instead of each getting a throwaway User of their own. It is the simplest way to offer a demo: no Users to create per visit and none to clean up afterwards. The cost is that every visitor sees and can change what any other visitor entered, and they share one Daily AI limit, so one visitor can use up the day's AI requests for the rest. The Guest is never reset; sabotage is unlikely, and its data can be restored by hand. Nothing a visitor did as the Guest carries over when they register, since the Guest's data belongs to everyone.
